# Liquid Glass Studio — Mobile

A separate mobile-first project for Liquid Glass Studio.

## Development rules

- GitHub is the source of truth.
- Do not use Lovable for this project.
- Build features incrementally and verify each phase before adding the next.
- Keep the existing desktop `fluid-glass-studio` project untouched.
- Do not modify Android or Windows projects/workflows unless explicitly requested.

## Phase 1

The initial foundation will contain only the basic mobile application structure, Liquid Glass Studio identity/icon, and authentication foundation. Features will be added one at a time after verification.
